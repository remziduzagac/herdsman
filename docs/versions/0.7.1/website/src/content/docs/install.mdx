---
title: Install Herdsman
description: Install, update, and verify Herdsman on Linux, macOS, and Windows beta.
---

Herdsman ships stable binaries for Linux and macOS. Native Windows support is preview-only beta.

## Install

On Linux or macOS, run:

```bash
curl -fsSL https://herdsman.invalid/install.sh | sh
```

On Windows preview beta, install the preview channel:

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://herdsman.invalid/install.ps1 | iex"
```

The installer downloads the right release binary for your platform and places it on your PATH. The Windows installer defaults to preview, writes that channel to Herdsman's config, uses versioned install folders, and updates a `current` junction, so updates do not need to overwrite a running `herdsman.exe`.

## Install with Homebrew

If you already use Homebrew:

```bash
brew install herdsman
```

## Install with mise

If you already use mise:

```bash
mise use -g herdsman
```

If mise reports `herdsman not found in mise tool registry`, update mise and retry. Older mise versions predate the Herdsman registry entry; `mise use -g github:OWNER_TBD/herdsman` works as a temporary fallback.

## Install with Nix

If you already use Nix, Herdsman provides a flake that builds Herdsman from source:

```bash
nix run github:OWNER_TBD/herdsman/v0.x.y
nix build github:OWNER_TBD/herdsman/v0.x.y
nix profile install github:OWNER_TBD/herdsman/v0.x.y
```

Replace `v0.x.y` with the latest release tag. You can omit the tag to track `master`, but release tags are recommended for normal installs.

The flake also exposes a development shell:

```bash
nix develop github:OWNER_TBD/herdsman
```

Update through the same Nix workflow you used to install Herdsman. For a profile install, list your profile entries and upgrade the Herdsman entry:

```bash
nix profile list
nix profile upgrade <index-or-name>
```

If Herdsman is an input in your own flake, update that input and rebuild your system, Home Manager, or development environment:

```bash
nix flake update herdsman
```

## Download manually

You can also download a binary from [GitHub releases](https://github.com/OWNER_TBD/herdsman/releases).

Choose the asset that matches your system:

| System | Asset |
| --- | --- |
| Linux x86_64 | `herdsman-linux-x86_64` |
| Linux aarch64 | `herdsman-linux-aarch64` |
| macOS Intel | `herdsman-macos-x86_64` |
| macOS Apple silicon | `herdsman-macos-aarch64` |

On Linux or macOS, make it executable and move it somewhere on your PATH.

```bash
chmod +x herdsman-linux-x86_64
mv herdsman-linux-x86_64 ~/.local/bin/herdsman
```

### Windows beta downloads

Windows binaries are published only on preview releases while native Windows support is in beta. Use the preview installer above for normal testing, or download the Windows asset from a preview GitHub prerelease:

| System | Asset |
| --- | --- |
| Windows x86_64 beta | `herdsman-windows-x86_64.exe` |

## Verify

Start Herdsman:

```bash
herdsman
```

If your shell cannot find `herdsman`, restart the terminal or check that the install directory is on your PATH.

## Update

Herdsman checks for new releases and notifies you in the app. You can update manually:

```bash
herdsman update
```

`herdsman update` is for installs managed by Herdsman's own installer. Homebrew, mise, and Nix installs are updated through those package managers instead.

On Linux and macOS, Herdsman uses the stable update channel by default. To opt into preview builds from `master`, set the channel:

```bash
herdsman channel set preview
```

Switch Linux and macOS direct installs back to stable the same way:

```bash
herdsman channel set stable
```

For direct installs, changing channels also checks that channel and installs its latest binary. If that update fails, run `herdsman update` to retry from the configured channel.

Preview builds are manually published GitHub prereleases from the current development branch. They are useful when you want fixes before the next stable release, but they can regress. Homebrew, mise, and Nix installs do not use the preview channel.

Windows beta builds are preview-only for now. `herdsman channel set stable` is rejected on Windows until stable Windows releases are available.

By default, `herdsman update` installs the new binary and leaves compatible running sessions alone. If an update changes Herdsman's client/server protocol, Herdsman asks whether to stop the old server after installing. Stop the old server to use the new version. Stopping exits pane processes. For the default session, run `herdsman server stop`, then run `herdsman` again. For a named session, run `herdsman session stop <name>`, then run `herdsman session attach <name>` again.

To opt into experimental live server handoff for supported running sessions, run:

```bash
herdsman update --handoff
```

Live handoff does not apply to Homebrew, mise, or Nix package-manager updates. For those installs, update with the package manager, then restart that Herdsman session when you are ready to use the new server. If a running session still uses the old server, stop it with `herdsman server stop` or `herdsman session stop <name>`, then run Herdsman again.

## Requirements

Stable Herdsman releases support Linux and macOS. Native Windows builds are preview-only beta releases; see [Windows beta](/docs/windows-beta/) for supported workflows and known limitations.
