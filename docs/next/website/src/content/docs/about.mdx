herdsman is a terminal workspace for running coding agents: workspaces, tabs and panes, SSH-connected machines, agents recognised by their state, and stacked panes.

![herdsman: a repository's worktrees sorted into sections in the sidebar, and an editor beside a stack of three agent panes](../../assets/screenshots/overview.webp)

## Based on herdr

herdsman is a modified version of [herdr](https://github.com/herdrdev/herdr), licensed under the [Apache License 2.0](https://github.com/remziduzagac/herdsman/blob/main/LICENSE). It keeps taking in herdr's releases: each herdsman release names the herdr release it is built on in the [changelog](https://github.com/remziduzagac/herdsman/blob/main/CHANGELOG.md).

herdsman runs as its own app beside herdr, with its own releases and packages, and adds features herdr does not have: stacked panes, tab presets, worktree sections and more. [What herdsman adds](/docs/what-herdsman-adds/) lists them all.

herdsman is not affiliated with or endorsed by the herdr project. Problems that also happen in herdr are best reported to herdr: a fix there reaches herdsman with the next merge.
